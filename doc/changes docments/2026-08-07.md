# Changes Documentation - 2026-08-07

- **Fixed Manager Reports (Consolidated Master DB Sales Reports) Data Persistence**:
  - **Node ID Foreign Key Mismatch Fix**: Standardized default `POS` node seeding in `src/db/seed.ts` to use `NODE_POS_001` and `NODE_ROOT_001` to prevent SQLite foreign key constraint failures during cash session and sales creation.
  - **Cash Session Foreign Key Protection**: Updated `useSessionStore.ts` (`openSession`) to automatically verify and resolve a valid POS node from the database before initializing cash sessions.
  - **Defensive Sales & Inventory Insertions**: Enhanced `src/services/bomService.ts` (`processSale` and `deductInventoryStock`) to ensure that referenced `node_id` and `session_id` records exist in `nodes` and `cash_sessions` tables prior to inserting sales records, sale items, and inventory audit logs.
  - **Product Foreign Key & Pre-Insert Validation**: Reordered `processSale` item processing in `bomService.ts` to verify and auto-insert product records in `products` table before executing `sale_items` insertion, resolving `sale_items.product_id` foreign key violations.
  - **Remote Sales Mapping Normalization**: Enhanced `loadSalesReport` in `ManagerPortalView.vue` to map remote backend orders (`order_id` -> `sale_id`, string to numeric net total, timestamp parsing) so remote and local sales merge accurately.
  - **Pre-existing DB Node Guarantee**: Updated `src/db/seed.ts` to check and guarantee `NODE_POS_001` node existence even when the database was previously seeded with dynamic UUID nodes.
  - **Local DB Schema Migrations Fix**: Added safe dynamic `ALTER TABLE` migrations in `src/db/client.ts` to automatically inject missing `sales` columns (e.g. `origin_branch_id`, `synced`) into pre-existing `pos.sqlite` files on developer machines, fixing silent insert failures.
  - **Surfaced SQLite Exceptions**: Removed aggressive error-swallowing in `client.ts` proxy driver, replacing it with an explicit `alert` to catch underlying schema/constraint violations during dev/QA testing.
  - **Configured Disk Storage Folder Selection & Direct SQLite Database Storage**:
    - **Native Directory Picker Integration**: Added native Electron directory dialog (`dialog:openDirectory`) in `InitialNodeSetupWizard.vue` (Step 4) and `DeveloperPortalView.vue` (Diagnostics tab), adding an interactive **"Select Folder"** button to pick any drive/directory on disk.
    - **Direct Custom Disk Database Writer**: Updated `electron/main.cjs` (`save-local-db` and `load-local-db` IPC handlers), `electron/preload.cjs`, and `src/db/client.ts` (`autoSave`, `initDb`, `saveDbToCustomFolder`) so that the actual live SQLite database file (`pos.sqlite`) is saved directly into the user's configured disk folder upon every auto-save/mutation, rather than defaulting strictly to Disk C (`%AppData%`).
  - **Dynamic Tax Groups & Product Tax Associations**:
    - **Dynamic Tax Group Loading**: Added `watch(() => props.show)` and `loadTaxes()` in `CreateProductModal.vue` so custom tax groups created in Manager Portal (`inclu tax`, `exclu 1`, `gst 2`) are dynamically fetched from SQLite whenever the product creation/edit modal opens, removing stale/hardcoded tax group fallbacks.
    - **Item-Level Tax Filtering**: Filtered out Whole Bill (`BILL`) taxes from product-level assignment so only item-level tax groups appear in the product creation modal.
  - **Whole Bill Tax & GST Calculation Engine Fix**:
    - **Active Bill Taxes Synchronization**: Added `fetchActiveBillTaxes` action to `useCartStore.ts` to automatically fetch active `BILL` tax groups (`tax_type === 'BILL'`) from SQLite and populate initial cart ticket snapshots upon store init and POS layout mount.
    - **Cart Summary Row Display**: Corrected summary box `v-if` condition in `LeftPane.vue` to check `cart.globalGstTax > 0`, rendering Whole Bill Tax additions accurately in the POS checkout summary pane.
  - **Role Login & PIN Switch Navigation Fix**:
    - **App View Navigation Sync**: Added `role-changed` event handling in `App.vue` and `LoginModal.vue` so entering a user PIN or selecting a role mode (Manager, Salesperson, Developer) automatically updates `currentAppView` back to the portal/dashboard view for the active role.
    - **Physical Keyboard PIN Input**: Added physical keyboard listener (`0`-`9`, `Backspace`, `Enter`, `Escape`) to `LoginModal.vue` so users can type PINs directly from their keyboard.
    - **Manager Portal Import Fix**: Restored missing `useSettingsStore` import in `ManagerPortalView.vue` which was causing a silent `ReferenceError` during Manager Portal component mounting.
  - **Item-Wise Sales & Tax Report Generator**:
    - **Date Range Filters & Presets**: Added `From Date` and `To Date` picker inputs along with quick preset buttons (`Today`, `This Week`, `This Month`, `All Time`) in `ManagerPortalView.vue` Tab 5.
    - **Item-Wise Sales Breakdown Table**: Aggregates sales line items across the selected date range to calculate Product Name & Barcode/SKU, Total Quantity Sold, Unit Price (Excl. Tax), Total Tax Collected on Product, and Line Total Amount (Incl. Tax).
    - **Bottom-Right Summary & Tax Breakdown Box**: Renders a dedicated summary box at the bottom right displaying Total Untaxed Base Amount, Effective Tax Percentage (e.g. `Tax (15.0% Rate)`), Total Tax Amount, and Grand Total Revenue.
    - **Print & CSV Export**: Added **"Print"** and **"Export CSV"** buttons allowing managers to print itemized tax reports or download structured CSV spreadsheets.
    - **Multi-Tax Row Splitting**: Updated aggregation grouping key in `ManagerPortalView.vue` to `${product_id}_tax_${unit_tax_per_item}` so that sales of the same item under different tax rates or rules are displayed as separate rows, each showing its own tax rate badge and line item totals.
  - **Universal Hardware Barcode Scanner Engine**:
    - **High-Speed Keyboard Wedge Buffer**: Implemented a global high-speed keydown event listener in `POSLayout.vue` that detects rapid keystrokes (<50ms intervals) sent by USB, Wireless, and Bluetooth barcode scanners without requiring manual focus on an input box.
    - **Automatic Product Lookup & Cart Addition**: Automatically matches scanned codes against product `barcode`, `sku`, or `id`, adding the item directly to the active cart and emitting an instant visual toast notification (`Scanned: [Product Name]`).
    - **Input Bar Search Handler**: Enhanced `handleBarcodeSearch` in `POSLayout.vue` to match scanned codes from the top search bar.
  - **Electron Fresh Install Setup & GitHub Release Manual Updater**:
    - **Single-File Setup Installer (.exe)**: Configured `electron-builder` with NSIS installer settings in `package.json` to package the app into a clean 91MB installer (`release/POS Enterprise System Setup 1.0.1.exe`) supporting custom install directory selection, desktop shortcut creation, and start menu integration.
    - **GitHub Release Manual Updater**: Integrated `check-github-release-update` and `open-external-url` IPC handlers in `electron/main.cjs` and `preload.cjs`, paired with Pinia `useUpdateStore.ts` and a dedicated UI card in `DeveloperPortalView.vue` to check GitHub Releases, display changelogs, and trigger update downloads.
    - **Repository Cleanup & Ignored Artifacts**: Cleaned up temporary scratch files and updated `.gitignore` to exclude build artifacts (`dist`, `dev-dist`, `release`, `out`, `.electron-user-data`).
