# Changes Summary - 2026-08-19

- Fixed SQLite database initialization error `SQLITE_NOTADB: sqlite3 result code 26: file is not a database`:
  - Added `isValidSqliteBuffer()` header validation in `src/db/client.ts` and `electron/main.cjs` to reject 0-byte or corrupted non-SQLite files.
  - Implemented automatic OPFS purge & recovery in `src/db/client.ts` if a corrupted `/pos.sqlite` file is encountered on startup.
  - Added atomic temporary file writing in `electron/main.cjs` for `save-local-db` to prevent partial or empty database file creation during disk saves.
