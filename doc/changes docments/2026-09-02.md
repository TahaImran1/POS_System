# Changes Summary - September 2, 2026

## Vue Template Closing Tag Fix

- **Product Creation Modal (`CreateProductModal.vue`)**:
  - Fixed syntax error where `<template v-else>` inside the assigned tax group dropdown was missing its `</template>` closing tag and `</select>` wrapper.
  - Verified clean Vue SFC template compilation and TypeScript build via `npx vue-tsc -b` (Exit Code 0).

## SQLite Database Migration & Designation Column Fix

- **Database Client (`client.ts`)**:
  - Added safe dynamic ALTER statements (`safeAlter`) during database startup for pre-existing SQLite database files (`pos.sqlite` / local OPFS disk):
    - `ALTER TABLE users ADD COLUMN designation TEXT DEFAULT 'Staff Member';`
    - `ALTER TABLE users ADD COLUMN rights TEXT;`
    - `ALTER TABLE products ADD COLUMN base_uom TEXT DEFAULT 'PCS';`
    - `ALTER TABLE products ADD COLUMN product_type TEXT NOT NULL DEFAULT 'FINISHED_GOOD';`
  - Fixed `SQLITE_ERROR: no such column: "designation"` when querying users on legacy pre-existing database files.

## Right to Assign Rights (`assign_rights`) System Permission

- **Authentication Store (`useAuthStore.ts`)**:
  - Added new system permission key `assign_rights` (*Right to Assign Rights*).
  - Granted `assign_rights` by default to Super Developer (`DEVELOPER` role & wildcard `['*']` rights).
  - Retained `manage_users` as the base user management permission.

## Equal User Architecture, Feature/Screen-Based Rights & Hierarchy

- **Equal User Architecture & Feature/Screen-Based Rights (`useAuthStore.ts`)**:
  - All users are equal in architecture and distinguished strictly by feature/screen capabilities assigned to them.
  - Refactored `SYSTEM_RIGHTS` into clean feature & screen capabilities (`pos_register_screen`, `purchase_order_inventory_screen`, `sales_returns_screen`, `reports_analytics_screen`, `user_management_screen`, `system_diagnostics_screen`, `apply_discounts`, `void_orders`, `cash_drawer_drops`, `manage_products`, `manage_inventory`, `manage_combos_bom`, `manage_taxes`, `vendor_payments`, `price_readjustment`, `manage_users`, `assign_rights`).

- **User "Reports To" Hierarchy (`schema.ts`, `schema.sql.ts`, `client.ts`, `useAuthStore.ts`)**:
  - Added `reports_to_user_id` column to `users` SQLite table with automatic safe startup migration (`safeAlter`).
  - Added **Reports To (Superior / Manager)** selector dropdown in both Developer Portal and Manager Portal user management modals.

- **Developer Portal User Editing (`DeveloperPortalView.vue`)**:
  - Enabled direct user editing in Developer Portal Configured System Accounts table (`handleEditUser`).
  - Allows editing user Full Name, Username, Designation, Reports To Manager, Secret PIN, and Granted Feature Rights.

- **Root Super Developer Protection (`useAuthStore.ts` & `DeveloperPortalView.vue`)**:
  - The Super Developer (Root user) holds wildcard `['*']` full access by default.
  - Enforced immutable protection: Super Developer rights cannot be revoked by anyone, and the root account cannot be deleted or locked out.
