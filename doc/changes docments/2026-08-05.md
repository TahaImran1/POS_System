# Changes - 2026-08-05

- **Inventory Stocking History & Movement Audit Feature (`pos_app`)**:
  - Added `inventory_logs` table in `src/db/schema.ts` to log product stocking movements (`RESTOCK`, `POS_SALE`, `BOM_DEDUCTION`, `MANUAL_ADJUSTMENT`, `INITIAL_SEED`).
  - Updated `src/db/seed.ts` to insert initial stock movement logs when seeding products.
  - Updated `src/services/bomService.ts` with `restockProduct()`, `getAllInventoryLogs()`, and automatic movement logging upon POS sales checkout and BOM ingredient deductions.
  - Created `src/views/InventoryHistoryView.vue` featuring summary cards, search & movement type filters, detailed stock movement timeline table, and an interactive **`+ Restock Product Inventory`** modal.

- **Manager-Only Inventory Control & PIN Authorization**:
  - Updated `src/stores/useAuthStore.ts` with `verifyManagerPin()` and `hasManagerPrivileges` getter.
  - Created `src/components/modals/ManagerPinModal.vue` to enforce Manager PIN verification for restricted operations.
  - Protected **`InventoryHistoryView.vue`** and **`CreateProductModal.vue`**: If a Salesperson/Cashier attempts to add or restock inventory, the system requires Manager PIN authentication before proceeding.

- **Open Cash Register Back Navigation Options**:
  - Updated `SessionModal.vue` to add a **`← Back`** button in the header and footer, allowing users to return to the POS Dashboard without forcing session creation.
  - Updated `POSDashboardView.vue` to add a **`← Back to Dashboard`** button in the Opening Cash Control float modal.

- **Moved Stock History to Manager Options Only**:
  - Removed `Stock History` tab from `POSLayout.vue` top navigation bar so cashiers/salespersons in POS register mode do not see stock management tabs.
  - Integrated `<InventoryHistoryView />` directly under **`ManagerPortalView.vue`** under **`Inventory & Stock History`** tab for store managers & owners.
