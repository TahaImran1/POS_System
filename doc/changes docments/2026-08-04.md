# Changes - 2026-08-04

- **Dynamic Branch Hierarchy Nodes & Demo Cleanup (`pos_app`)**:
  - Removed hardcoded node names (`HQ Cloud` and `Downtown Flagship`) from `src/db/seed.ts`.
  - Updated `InitialNodeSetupWizard.vue` so completing Phase 1 Setup dynamically updates/creates branch hierarchy nodes matching the user's store name (e.g., `M1 HQ` and `M1 POS Terminal`).
  - Added a **`Delete Node`** button for each card under **Branch Hierarchy Nodes** in `DeveloperPortalView.vue`.

- **Hierarchical First-Time Setup Wizard Sequence**:
  - Re-structured `InitialNodeSetupWizard.vue` into a strict 6-step onboarding workflow:
    1. **Step 1 (App Deployment Role)**: Select POS Terminal (Active Target) vs Branch Server vs HQ Node.
    2. **Step 2 (POS System Type)**: Select Restaurant POS (Table Canvas, KOT) vs Store / Retail POS (Barcode Scanner Grid).
    3. **Step 3 (Developer PIN Setup)**: Prompt Developer to enter custom Developer PIN Code & Name.
    4. **Step 4 (Developer Creates Manager & Store)**: Developer configures Store Name, Manager Username, Manager Name, Manager PIN, and DB Path.
    5. **Step 5 (Manager Creates Salespersons)**: Manager creates Salesperson / Cashier accounts (Name, Username, PIN Code) with `+ Add Salesperson` functionality.
    6. **Step 6 (Launch Workspace)**: Saves all created accounts cleanly to SQLite `schema.users` table and launches workspace.

- **Store / Retail POS vs Restaurant POS UI & Functional Differentiation**:
  - **`POSLayout.vue`**: Hides `Tables` button in Retail POS mode. Displays `🛒 Store / Retail POS` badge and dedicated Barcode Scanner input field in header.
  - **`LeftPane.vue`**: Disables restaurant course headers in Retail mode, rendering a clean itemized retail cart.
  - **`Numpad.vue`**: Tailored quick actions for Retail (`Pricelist`, `Refund`, `Discount %`) vs Restaurant (`Course`, `Upload`, `Fire Course`, `Guests`).
  - **`ProductCard.vue`**: Displays real-time stock quantity badges (`Stock: 100`) and barcode tags (`#OD001`) on product cards when in Retail POS mode.

- **Single Store Initialization & Terminal Deletion**:
  - Updated `useSettingsStore.ts` to remove the default fallback array (`Main Flagship Store`).
  - Added `setSingleTerminal()` in setup wizard so initializing a store replaces old dummy stores with strictly the created store.
  - Added a delete button on each card in `POSDashboardView.vue` (`handleDeleteTerminal`) allowing manual removal of any outlet card.

- **SQLite Database Orders Query Integration**:
  - Updated `OrdersView.vue` (`loadCompletedSales`) to fetch completed sales records directly from SQLite `schema.sales` and `schema.sale_items`.
  - Completed orders now display in Orders View with receipt ID, date/time, **`PAID`** green badge, payment method, tax total, and full itemized list preview.

- **Automatic Real-Time Inventory & Raw Material BOM Deduction**:
  - Updated `bomService.ts` (`processSale`) to match products by `product_id`, `barcode`, or `sku` and upsert inventory records in `schema.inventory`.
  - Configured automatic raw material ingredient deduction (`bom.quantity_required * soldQty`) for `FINISHED_GOOD` products.
  - Configured real-time in-memory stock reload in `useProductStore.ts` so `ProductCard.vue` stock badges (`Stock: {{ product.stock }}`) refresh immediately on screen after checkout.
