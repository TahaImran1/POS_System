## Cryptographic Security & Universal PIN Hashing

- **Web Crypto Hashing Utility (`src/utils/crypto.ts`)**:
  - Implemented universal SHA-256 password hashing utility using standard `globalThis.crypto.subtle` Web Crypto API.
  - Includes `hashPin(pin)`, `isHashedPin(pin)`, and `comparePin(plainPin, storedPin)`.
  - Avoids plaintext password storage anywhere in SQLite or memory states.

- **Automated Database Migration & Seed Security (`seed.ts`, `useAuthStore.ts`)**:
  - Default developer seed PIN (`1234`) is seeded as an SHA-256 hash.
  - Startup migration in `useAuthStore.ts` checks existing SQLite records and transparently migrates any legacy plaintext PINs to SHA-256 hashes on boot.
  - `addUser` and `updateUser` actions automatically hash input PINs before saving to SQLite.
  - Preserves existing hashed PINs when editing user profiles if PIN field is left blank.

- **UI & Modal Integration (`ManagerPortalView.vue`, `DeveloperPortalView.vue`, `ManagerPinModal.vue`)**:
  - Masked user PIN display in management tables (`•••••• (Secured)`).
  - Updated `ManagerPinModal.vue` to asynchronously verify input against hashed PIN values using `comparePin`.

## Developer Role Access & Enterprise Navigation Architecture

- **Root Cause of Missing Features for Developer**:
  - Previously in `src/App.vue`, conditional rendering checked `authStore.isDeveloper` before `authStore.isManager` and immediately routed developers to `DeveloperPortalView`.
  - As a result, users with the Developer role (super admins with `*` permissions) were permanently confined to technical diagnostics, unable to switch to the POS Register, Products Catalog, BOM Recipes, Taxes, Inventory/POs, or Sales Reports.

- **Universal Multi-Module Navigation Header (`src/App.vue`)**:
  - Added enterprise navigation tabs to the top header bar:
    1. **POS Register**: Direct access to the live sales terminal, ticket grid, and restaurant floor plan.
    2. **Manager Portal**: Products catalog, BOM recipes, tax setup, inventory restocks/POs, and sales analytics.
    3. **Developer Portal**: Database sync, branch node hierarchy, diagnostic metrics, and user management.
    4. **Node & Sync**: Branch hierarchy and VPS cloud database sync.
  - Retained session view state (`pos_active_view`) in `sessionStorage` so view selection persists across page refreshes.
  - Added direct navigation shortcuts (`Open POS Register`, `Open Manager Portal`) to the Developer Portal banner.
  - Validated clean production build with `npm run build` (`vue-tsc -b && vite build`) with zero errors.
