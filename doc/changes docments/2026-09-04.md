# Changes Summary - September 4, 2026

## Separation of Product Master Definition vs Inventory Restock & Pricing Architecture

- **Product Master Definition Modal (`CreateProductModal.vue`)**:
  - Aligned Product Definition with retail & POS industry standard architecture:
    - Product Definition handles **Product Identity** (Name, Barcode/SKU, Classification, Tax Group, Category, Image, Description, and UOM Multiplier hierarchy structure like Piece ➔ Pack ➔ Carton).
    - Removed manual Sales Price and Initial Stock edit fields from Product Definition modal.
    - Added an architecture info banner clarifying that inventory stock additions, purchasing cost rates, and active retail selling prices are established strictly through **Purchase Orders (POs)**, **Inventory Restocks**, and **Price Readjustments** in the Inventory module.
  - Added read-only **Current Inventory Stock** and **Current Active Selling Price** status indicators in edit mode.
  - Updated `executeCreateProduct` and `executeUpdateProduct` to preserve inventory stock levels and pricing records managed via the Inventory module.
  - Verified clean TypeScript build via `npx vue-tsc -b` (Exit Code 0).

## 3-Layer Buying Price Architecture

- **Database Schema & Dynamic Migrations (`schema.ts`, `schema.sql.ts`, `client.ts`)**:
  - Added `cost_price: real('cost_price').notNull().default(0)` to `products` table.
  - Added `vendor_product_prices` table to track agreed purchasing prices per vendor, product, and UOM tier (`id`, `vendor_id`, `product_id`, `uom_name`, `last_buying_price`, `updated_at`).
  - Added safe startup dynamic migrations (`safeAlter`) for `products.cost_price` and `vendor_product_prices`.

- **Multi-Vendor Pricing Services (`vendorService.ts`)**:
  - Implemented `getVendorProductPrice(vendorId, productId, uomName)` to query historical agreed rates for suppliers.
  - Implemented `recordVendorProductPrice(vendorId, productId, uomName, costPrice)` to upsert agreed rates when Purchase Orders are placed.

- **Purchase Order Cost Synchronization (`bomService.ts`)**:
  - Updated `processBatchInventoryAdjustment` to automatically update `products.cost_price` and `product_uom.cost_price` upon PO delivery.
  - Automatically records vendor agreed rates into `vendor_product_prices`.

- **Purchase Order Register Integration (`InventoryHistoryView.vue`)**:
  - Selecting a supplier in the PO register automatically looks up and pre-fills that vendor's last agreed buying price for any added products.
  - Displayed live **Last Master Buying Cost** and **Estimated Margin / Pc** indicator inside each line item card.
