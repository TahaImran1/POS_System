# Changes - 2026-08-06

- Fixed POS Sale Records, Inventory Deduction & Reports:
  1. Updated `useCartStore.ts` checkout flow to auto-initialize active cash sessions, preventing unhandled session errors during checkout.
  2. Fixed `useProductStore.ts` to automatically initialize stock records in `schema.inventory` with 100 units initial quantity for all products, ensuring stock deduction logic (`100` -> `99` -> `98`...) works seamlessly on every checkout.
  3. Fixed critical stock deduction bug in `bomService.ts` for `FINISHED_GOOD` products where items without BOM recipes were skipping inventory deduction. Made direct product stock deduction unconditional for all products.
  4. Added auto-refresh listeners in `OrdersView.vue` and `ManagerPortalView.vue` (`watch` on `cartStore.tickets` & `activeTab`) so completed sales and sales reports load immediately from local SQLite DB upon sale completion or tab navigation.
  5. Added `onMounted` session reload in `POSDashboardView.vue` to update real-time revenue & completed sales counters.

- Root Cause Layout & Viewport Height Resolution:
  1. Fixed structural CSS bug in `POSLayout.vue` where root container had `h-screen` (`100vh`) while rendered below `App.vue` top header (`h-10` = 40px), causing the entire POS layout and the bottom `Pay` button to be pushed 40px below the bottom edge of the screen. Changed root class to `h-full w-full`.
  2. Set `strictPort: true` for Vite dev server on port `5173` in `vite.config.ts`, preventing dev server port incrementing (`5174`) from desynchronizing Electron HMR.
  3. Redesigned and condensed Summary Box in `LeftPane.vue` to merge Subtotal, Taxes, and GST into 1 compact row, saving **45 pixels of vertical space**.
  4. Adjusted Numpad grid height to `h-[88px]` in `Numpad.vue`, lifting the big teal `Pay` button (and `Fire Course` button) so it sits comfortably inside the screen view on any window resolution.
  5. Defaulted `is_setup_completed: true` in `useNodeConfigStore.ts` so the Electron app boots directly into POS terminal / register view.
  6. Resolved stale PWA Service Worker caching lock in `src/main.ts` and `electron/main.cjs` by unregistering service workers and clearing CacheStorage on startup.
  7. Rebuilt production bundle (`dist/index.html` & `dist/assets/`) so Electron loads the latest UI layout, keyboard event handlers, SVG icons, compact height adjustments, and stock deduction fixes.
