# Changes Summary - July 27, 2026

## 3-Tier User Role Architecture & Developer / Manager / Salesperson System Implementation

- **Database Schema Enhancements (`src/db/schema.ts` & `src/db/schema.sql.ts`)**:
  - Added `users` table (`user_id`, `username`, `name`, `pin`, `role`, `node_id`, `created_at`).
  - Added `app_settings` table (`setting_id`, `key`, `value`, `updated_at`).
  - Updated WASM SQLite DDL initializer and `src/db/seed.ts` to automatically seed default accounts (Developer `dev`: PIN 1234, Manager `manager`: PIN 5555, Salesperson `cashier`: PIN 0000) and app settings.

- **Authentication & User Role Store (`src/stores/useAuthStore.ts`)**:
  - Implemented PIN verification, profile switching, and role capability checks (`DEVELOPER`, `MANAGER`, `SALESPERSON`).
  - Implemented CRUD helpers for user account management.

- **Master DB & Branch Node Store (`src/stores/useMasterDbStore.ts`)**:
  - Created store for configuring VPS/Cloud Master DB server host URL, WebSocket sync URL, API keys, and connection testing.
  - Implemented branch node hierarchy management (`ROOT`, `REGION`, `CITY`, `BRANCH`, `POS`).

- **Developer / Super Admin Portal (`src/views/DeveloperPortalView.vue`)**:
  - Built Master DB connection management tab with live VPS health testing.
  - Built User Accounts & Roles management tab for creating accounts, setting PINs, and linking branch nodes.
  - Built Branch Node Hierarchy management tab to visually create and modify multi-branch nodes.
  - Built Diagnostics tab for inspecting local SQLite, Master DB link, and WebSocket sync daemon.

- **Store Manager / Owner Portal (`src/views/ManagerPortalView.vue`)**:
  - Built Master Product Catalog management tab for creating products directly on Master DB.
  - Built Combos & Bill of Materials (BOM) recipe builder tab.
  - Built Tax Setup & Tax Groups tab (VAT rate %, inclusive/exclusive rules).
  - Built Inventory & Stock control balances tab per branch.
  - Built Sales Reports & Analytics tab querying Master DB directly for consolidated transaction metrics.

- **Fastify Server REST API Enhancements (`server/src/index.ts`)**:
  - Added REST endpoints for Node hierarchy management (`GET /api/nodes`, `POST /api/nodes`).
  - Added REST endpoints for User management (`GET /api/users`, `POST /api/users`).
  - Added REST endpoint for direct sales reporting (`GET /api/reports/sales`).

- **Unified Navigation & PIN Security Dialog (`src/App.vue` & `src/components/modals/LoginModal.vue`)**:
  - Added top Universal Master Bar with real-time mode indicator and quick role switcher badges.
  - Created `LoginModal.vue` dialog with on-screen PIN keypad for switching between Developer, Manager, and Salesperson profiles.
